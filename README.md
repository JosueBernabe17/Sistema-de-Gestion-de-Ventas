# Sistema-de-Gestion-de-Ventas
Este proyecto consiste en un sistema de ventas robusto basado en SQL Server, diseñado para gestionar de manera eficiente clientes, productos, usuarios, roles, permisos, compras y ventas. La estructura incluye múltiples tablas relacionadas para garantizar un control integral de las operaciones comerciales.
Aquí tienes la versión más concisa:

## Características Principales

1. **Gestión de Clientes**: 
   - Registro de información básica y relación con ventas.

2. **Gestión de Productos**:
   - Clasificación por categoría y detalles como nombre, precio y proveedor.

3. **Control de Ventas**:
   - Registro de transacciones con detalles de productos vendidos y método de pago.

4. **Gestión de Compras**:
   - Registro de compras a proveedores con desglose de productos adquiridos.

5. **Roles y Permisos**:
   - Gestión de usuarios con roles y permisos definidos para control y seguridad.

6. **Relación con Proveedores**:
   - Registro detallado de proveedores de productos.
